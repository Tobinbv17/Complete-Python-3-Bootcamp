CAR-T Target Evaluation Framework (Rubrix) for Colorectal Cancer Indications
Evaluating candidate cell therapy targets for CAR-T development required a systematic multi-omics analytical framework to assess target density, tumor specificity, and subtype alignment. We established an automated evaluation workflow integrating public cohorts (TCGA, GTEx, MET500, CPTAC) and real-world clinical datasets (Caris RWD360) to profile key literature targets (LY6G6D, CEACAM5, EPCAM, ERBB2, MSLN, TACSTD2, PROM1, EGFR, FOLR1, CDH17, and GUCY2C). The pipeline benchmarked tumor vs. normal expression, evaluated mRNA-to-protein translational concordance, and profiled target abundance across Consensus Molecular Subtypes (CMS). Executing and documenting this evaluation within CodeOcean ensured full reproducibility, dynamic data tracking, and rapid decision-making as target candidate priorities and indication strategies evolve.
